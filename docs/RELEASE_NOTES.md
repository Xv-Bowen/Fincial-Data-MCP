# 首次开源快照

基于应用版本 1.4.1，保留现有完整网站与 MCP 实现。该快照采用全新的 Git 历史，不复制生产仓库历史和运行状态。

- 移除原项目标识、真实资源链接、个人配置与原站点的运行时绑定。
- 增加 MIT 许可证、第三方说明、Sites 部署指南、配置表、工具目录、常见故障、发布审计与贡献说明。
- 站点地址改为运行时 SITE_ORIGIN，拒绝不安全或带路径的配置；MCP 完成结果补齐 resultType、serverInfo 元数据和发现/列表缓存字段。
- 原无明确许可证的 Ashare vendored 文件替换为项目自有日线兼容适配，保留本应用使用的新浪不复权和腾讯前复权两条能力；不含该第三方库未使用的分钟/周/月 API。

此次开源准备没有更新原生产服务。测试结果与验证边界见发布审计；依赖安装成功不等于上游数据接口永久可用，也不等于某个部署者的所有权限已经开通。
